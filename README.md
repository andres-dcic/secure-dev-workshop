# Repositorio para Killercoda

Este repositorio contiene la base para subir un ejercicio/scenario a Killercoda.

Contenido inicial:
- README con instrucciones
- .gitignore para evitar archivos locales
- LICENSE (MIT)

Instrucciones para usar:
1. Añadir o crear tu escenario en este repositorio.
2. Añadir el remoto de GitHub (o el repo que te indique Killercoda):
   git remote add origin <URL>
3. Subir al remoto:
   git push -u origin main

Si necesitas un template específico para Killercoda (archivos de escenario), indícalo y lo añado.
